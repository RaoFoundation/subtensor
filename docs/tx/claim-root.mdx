Root dividends accrue as shares of each validator's basket — an escrowed
index fund of subnet alpha. This call redeems the signing coldkey's owed
shares on **every** validator it root-stakes to: each basket pays out
pro-rata (subnet alpha holdings are sold to TAO at the current pool price)
and the proceeds are staked back to root on the same validator.

The `subnets` argument is retained so pre-basket clients' encoded call data
still decodes at call index 121; it is **ignored**. Baskets have no
per-subnet claim selection — redemption is always fund-level.

Prefer [`claim-root-with-hotkey`](/docs/tx/claim-root-with-hotkey) to claim
a single validator, or `btcli root claim` for an interactive picker.
Claims whose estimated per-validator payout is below the chain's claim
threshold (see `root_claim_threshold`) are silently skipped and keep
accruing. Preview with `root_basket_owed` /
`root_basket_owed_breakdown`.

## Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `subnets` | list[int] | no (default `[0]`) | Ignored. Kept for old-client call-data compatibility. |

## CLI

```bash
btcli tx claim-root --subnets 0 --dry-run
btcli tx claim-root -w my_coldkey
```

For a single validator, prefer:

```bash
btcli root claim --hotkey 5F... -w my_coldkey
btcli root claim --hotkey 5F... --amount all
btcli tx claim-root-with-hotkey --hotkey 5F...
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey")
intent = bt.ClaimRoot(subnets=[0])

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

Or build the intent by op name:

```python
result = sub.execute_tool("claim_root", {"subnets": [0]}, wallet)
```

## On-chain implementation

`SubtensorModule.claim_root` — call index 121. `subnets` is accepted and
discarded; the pallet walks `StakingHotkeys` for the coldkey and redeems
each validator fund-level via `do_root_claim`.
