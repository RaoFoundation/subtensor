A permanent epoch tombstone prevents revoked signatures from becoming
valid after reinstalling. Expiry is a block number, not an order timestamp.
UnrestrictedTrading explicitly permits every trade until expiry/revocation.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | HashedAccounts | [`HashedAccounts.install_capability`](/code/pallets/hashed-accounts/src/lib.rs#L311-L323) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `expected_epoch` | integer | yes | Finalized owner/Order epoch plus one. |
| `key_commitment` | string | yes | 64-byte commitment to the purpose-specific ML-DSA order public key, in hex. |
| `expires_at` | integer | yes | Inclusive chain block-number expiry. |
| `scope` | object | yes | Explicit Trading bounds, or UnrestrictedTrading. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.
