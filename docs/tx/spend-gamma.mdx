Destroys `amount_gamma` of the deposit and adds it to what the hotkey has
spent at the service at `service_hotkey_ss58`, which credits it. The
amount is at least 0.1 gamma unless it empties the deposit, and within its
balance and what its daily spend cap allows. Signed by the hotkey, which
pays no fee: the chain refuses an invalid spend before it enters a block.

| `hotkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.spend_gamma`](/code/pallets/subtensor/src/macros/dispatches.rs#L3332-L3341) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the deposit and the service. |
| `service_hotkey_ss58` | string | yes | Hotkey of the service spent at. |
| `amount_gamma` | number | yes | Gamma spent. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.SpendGamma(netuid=1, service_hotkey_ss58="5F...", amount_gamma=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```
