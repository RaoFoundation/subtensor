Takes at most `amount_tao` and `amount_tusd` in the pool's current
ratio, so one of the two is usually not used in full. Shares earn the
pool's swap fees: they redeem a growing part of both reserves. The first
deposit sets the price and must be within 2% of the TAO/USD oracle price.
Fails rather than receiving fewer shares than the reserves now give, less
`rate_tolerance`.

| `coldkey` | signed account (pallet role may apply) | CanonicalPool | [`CanonicalPool.add_liquidity`](/code/pallets/canonical-pool/src/lib.rs#L333-L343) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `amount_tao` | number | yes | The most TAO to add. |
| `amount_tusd` | number | yes | The most tUSD to add. |
| `rate_tolerance` | number | no | Maximum fall of what you receive below the current quote, as a fraction (0.05 = 5%). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx add-pool-liquidity \
  --amount-tao <amount> \
  --amount-tusd <amount> --dry-run
btcli tx add-pool-liquidity \
  --amount-tao <amount> \
  --amount-tusd <amount> -w my_coldkey
```

import bittensor as bt

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
