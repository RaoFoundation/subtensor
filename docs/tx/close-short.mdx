`alpha` defaults to the whole position. Closing the whole position
refunds the remaining funds and the deposit to the owner; a partial close
refunds nothing. `max_tao_in` caps the buy-back cost; omit it to use the
runtime close quote plus `rate_tolerance`. The buy-back is paid from the
position's custody, never from the wallet. Works while lending is
disabled.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.close_short`](/code/pallets/lending/src/lib.rs#L1187-L1198) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the short. |
| `alpha` | number | no | Alpha to buy back and burn. Omit to close the whole position. |
| `max_tao_in` | number | no | Most TAO the buy-back may cost. Omit to quote it. |
| `rate_tolerance` | number | no | Tolerance applied to the quote when the floor or ceiling is omitted, as a fraction (0.005 = 0.5%). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.CloseShort(netuid=1)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```
