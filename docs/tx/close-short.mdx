Buys `amount_alpha` of alpha from the pool and retires it, paying from
the position's proceeds and then its collateral. `all` closes the whole
position, which returns the remaining collateral and the deposit to your
free balance. Interest due is settled from the collateral first.
Fails rather than paying more than the current quote plus
`rate_tolerance`. A plan's `preview` holds the quote's `alpha`,
`cost_tao`, `maximum_cost_tao`, `from_proceeds_tao`,
`from_collateral_tao`, `interest_tao` and whether the close is
`full`.

| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.close_short`](/code/pallets/lending/src/lib.rs#L670-L680) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the short. |
| `amount_alpha` | number \| `"all"` | no | Alpha bought back, or ``all`` to close the whole short. |
| `rate_tolerance` | number | no | Maximum rise of the buy-back's TAO cost above the quote, as a fraction (0.05 = 5%). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx close-short \
  --netuid <int> --dry-run
btcli tx close-short \
  --netuid <int> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.CloseShort(netuid=1)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("close_short", {...}, wallet)
```
