Supports direct ML-DSA owners, proxies, derivatives, and multisigs. This
grants relayers the complete specified trade; funds move only on execution.
Cancel with the same nonce and complete order to revoke its unfilled part.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | LimitOrders | [`LimitOrders.authorize_order`](/code/pallets/limit-orders/src/lib.rs#L766-L800) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `nonce` | integer | yes | Permanent owner-local u64 order nonce. |
| `order` | object | yes | Complete V1 or V2 VersionedOrder, including every economic term. |
| `order_data` | string | no | Optional pinned canonical VersionedOrder SCALE bytes as hex. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## On-chain implementation

```rust
#[pallet::call_index(5)]
#[pallet::weight(T::WeightInfo::authorize_order())]
#[transactional]
pub fn authorize_order(
    origin: OriginFor<T>,
    order: VersionedOrder<AccountId32>,
) -> DispatchResult {
    let who = ensure_signed(origin)?;
    ensure!(order.signer() == &who, Error::<T>::Unauthorized);
    let (nonce, terms) = order
        .authorized_terms()
        .ok_or(Error::<T>::InvalidAuthorizationMode)?;
    ensure!(
        LimitOrdersEnabled::<T>::get(),
        Error::<T>::LimitOrdersDisabled
    );
    ensure!(
        T::AuthenticatedOrderSignerFilter::contains(&who),
        Error::<T>::OrderSignerFrozen
    );
    let id = Self::derive_authorized_order_id(nonce, &terms);
    Self::check_order_nonce(&who, nonce, id)?;
    ensure!(
        !Orders::<T>::contains_key(id),
        Error::<T>::OrderAlreadyProcessed
    );
    OrderNonces::<T>::insert(&who, nonce, id);
    ApprovedOrders::<T>::insert(id, Self::order_approval_commitment(nonce, &terms));
    Self::deposit_event(Event::OrderApproved {
        order_id: id,
        signer: who,
        nonce,
    });
    Ok(())
}
```
