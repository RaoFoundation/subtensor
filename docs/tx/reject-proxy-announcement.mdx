Must be signed *as the real account*. For a keyless pure proxy that means
dispatching through a proxy relationship that can reach this call — typically
impractical during the same delay window, which is why protected-account
cancel uses `remove_proxy_announcement` (delegate path) instead.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Proxy | [`Proxy.reject_announcement`](/code/pallets/proxy/src/lib.rs#L561-L578) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `delegate_ss58` | string | yes | Delegate that made the announcement. |
| `call_hash` | string | yes | Hash previously announced by the delegate (0x-prefixed hex). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## On-chain implementation

`Proxy.reject_announcement` — [`pallets/proxy/src/lib.rs#L566`](/code/pallets/proxy/src/lib.rs#L561-L578):

```rust
#[pallet::call_index(8)]
#[pallet::weight(T::WeightInfo::reject_announcement(
    T::MaxPending::get(),
    T::MaxProxies::get()
))]
pub fn reject_announcement(
    origin: OriginFor<T>,
    delegate: AccountIdLookupOf<T>,
    call_hash: CallHashOf<T>,
) -> DispatchResult {
    let who = ensure_signed(origin)?;
    let delegate = T::Lookup::lookup(delegate)?;
    Self::edit_announcements(&delegate, |ann| {
        ann.real != who || ann.call_hash != call_hash
    })?;

    Ok(())
}
```
