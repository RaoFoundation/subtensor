Redeems the signing coldkey's owed basket shares on **one** validator only.
That basket pays out pro-rata (subnet alpha holdings are sold to TAO at the
current pool price) and the proceeds are staked back to root on the same
validator. Other validators' accrued yield is left untouched.

Claims whose estimated payout is below the chain's claim threshold
(see `root_claim_threshold`) are silently skipped and keep accruing; there
is no deadline. Preview per-validator payouts with
`root_basket_owed_breakdown`. For a coldkey-wide claim that old clients
still encode, see [`claim-root`](/docs/tx/claim-root).

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.claim_root_with_hotkey`](/code/pallets/subtensor/src/macros/dispatches.rs#L1955) |

## Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `hotkey` | ss58 | yes | Validator whose accrued basket yield to claim. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Prefer the root suite (claim accrued, or withdraw with `--amount`):

```bash
btcli root claim
btcli root claim --hotkey 5F... -w my_coldkey
btcli root claim --hotkey 5F... --amount all
btcli tx claim-root-with-hotkey --hotkey 5F... --dry-run
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey")
intent = bt.ClaimRootWithHotkey(hotkey_ss58="5F...")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

Or build the intent by op name:

```python
result = sub.execute_tool(
    "claim_root_with_hotkey",
    {"hotkey_ss58": "5F..."},
    wallet,
)
```

## On-chain implementation

`SubtensorModule.claim_root_with_hotkey` — call index 148. Redeems only the
given validator via `do_root_claim(coldkey, vec![hotkey])`.
