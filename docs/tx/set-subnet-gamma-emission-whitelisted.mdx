A subnet owner's gamma share may only name a subnet on this whitelist (see
the `set_subnet_emission_weights` intent). Removing a subnet removes every
gamma share to it: each share is added to the paying subnet's miner slot and
its unconverted alpha to that subnet's pending miner emission.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet to whitelist or remove from the whitelist. |
| `whitelisted` | boolean | yes | True to whitelist the subnet, false to remove it. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58

## On-chain implementation

`AdminUtils.sudo_set_subnet_gamma_emission_whitelisted` — [`pallets/admin-utils/src/lib.rs#L3041`](/code/pallets/admin-utils/src/lib.rs#L3038-L3062):

```rust
#[pallet::call_index(121)]
#[pallet::weight(<T as Config>::WeightInfo::sudo_set_subnet_gamma_emission_whitelisted()
    .saturating_add(pallet_subtensor::Pallet::<T>::remove_gamma_emission_target_weight()))]
pub fn sudo_set_subnet_gamma_emission_whitelisted(
    origin: OriginFor<T>,
    netuid: NetUid,
    whitelisted: bool,
) -> DispatchResult {
    ensure_root(origin)?;
    ensure!(
        pallet_subtensor::Pallet::<T>::if_subnet_exist(netuid),
        Error::<T>::SubnetDoesNotExist
    );
    ensure!(!netuid.is_root(), Error::<T>::NotPermittedOnRootSubnet);
    if whitelisted {
        pallet_subtensor::SubnetGammaEmissionWhitelisted::<T>::insert(netuid, true);
    } else {
        pallet_subtensor::Pallet::<T>::remove_gamma_emission_target(netuid);
    }
    Self::deposit_event(Event::SubnetGammaEmissionWhitelistedSet {
        netuid,
        whitelisted,
    });
    Ok(())
}
```
