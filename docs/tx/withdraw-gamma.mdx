Moves up to `amount_gamma` (`all` for the whole deposit) from the
deposit at `hotkey_ss58` to your coldkey's gamma balance: the whole
deposit, or at least 0.1 gamma leaving at least as much. A withdrawal that
empties the deposit closes it.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.withdraw_gamma`](/code/pallets/subtensor/src/macros/dispatches.rs#L3313-L3322) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the deposit and the balance. |
| `hotkey_ss58` | string | yes | Hotkey of the deposit withdrawn from. |
| `amount_gamma` | number \| `"all"` | yes | Gamma withdrawn. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.WithdrawGamma(netuid=1, hotkey_ss58="5F...", amount_gamma=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```
