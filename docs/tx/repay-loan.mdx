Same wallet vs escrow paths as :class:`CloseLoan`, but settles a
`principal_part` slice (`k = principal_part / principal`). When
`principal_part` equals the full principal the runtime closes. Units
and hotkey rules match close: `principal_part` is alpha for a short and
TAO for a long; `max_payment` / `min_refund` follow the close-path
asset for the saved side and `repay_from_wallet` flag.

On fork / clone chains without a live MEV decryptor, submit with
`--no-mev-shield`.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.repay`](/code/pallets/lending/src/lib.rs#L1625-L1651) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the position to repay. |
| `principal_part` | number \| `"all"` | yes | Principal to repay: alpha for a short, TAO for a long. Must be > 0 and ≤ stored principal; equals full principal to close. |
| `max_payment` | number \| `"all"` | yes | Maximum repayment: TAO, or alpha for a wallet-repaid short. |
| `min_refund` | number \| `"all"` | no | Minimum returned collateral: TAO for shorts, alpha for longs. |
| `hotkey_ss58` | string | no | Hotkey for alpha repay (short wallet path) or alpha refund (long repay). Required whenever alpha moves; short escrow buyback (from-escrow) may omit it. |
| `repay_from_wallet` | boolean | no | False (default): buy short alpha back from escrow / sell long escrow. True: repay short alpha from hotkey stake, or pay long TAO from wallet. |
| `valid_until` | integer | no | Latest block number that may include this repay. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.RepayLoan(netuid=1, principal_part=1.0, max_payment=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("repay_loan", {...}, wallet)
```

## On-chain implementation

```rust
#[pallet::call_index(6)]
// Full repay delegates to `do_close`; charge the heavier of the two measured
// paths so the close-path R/W budget is never undercharged (Auditor fid:424daaa1).
#[pallet::weight(T::WeightInfo::close().max(T::WeightInfo::repay()))]
#[transactional]
pub fn repay(
    origin: OriginFor<T>,
    netuid: NetUid,
    hotkey: T::AccountId,
    principal_part: u64,
    repay_from_wallet: bool,
    max_payment: u64,
    min_refund: u64,
    valid_until: BlockNumberFor<T>,
) -> DispatchResult {
    let owner = ensure_signed(origin)?;
    Self::do_repay(
        owner,
        netuid,
        hotkey,
        principal_part,
        repay_from_wallet,
        max_payment,
        min_refund,
        valid_until,
    )
}
```
