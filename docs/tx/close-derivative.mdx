The owner may close at any time. After the position's expiry anyone may
close it on the owner's behalf, so the pool always gets its liquidity back.
Settlement reverses the opening trade, repays the pool plus the borrow
fee, and pays the owner what remains in TAO. If the position is underwater
the pool absorbs the shortfall and the owner gets nothing back.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet the position is on. |
| `side` | string | yes | Which position to close: `Short` or `Long`. |
| `owner_ss58` | string | no | Coldkey that owns the position. Defaults to the signer; pass another owner only to close their expired position. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

```rust
#[pallet::call_index(1)]
#[pallet::weight(T::WeightInfo::close())]
pub fn close(
    origin: OriginFor<T>,
    owner: T::AccountId,
    netuid: NetUid,
    side: Side,
) -> DispatchResult {
    let caller = ensure_signed(origin)?;
    let position =
        Positions::<T>::get(&owner, (netuid, side)).ok_or(Error::<T>::NoPosition)?;
    if caller != owner {
        ensure!(
            frame_system::Pallet::<T>::block_number() >= position.expires_at,
            Error::<T>::NotExpired
        );
    }
    Self::do_settle(&owner, netuid, side, Closer::Account(caller)).map(|_| ())
}
```
