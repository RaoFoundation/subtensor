Each signed order includes complete terms, its signature, and an optional
partial fill. Authorized terms also bind an owner-local nonce. With
should_fail true, any failed order reverts the whole batch.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | LimitOrders | [`LimitOrders.execute_orders`](/code/pallets/limit-orders/src/lib.rs#L613-L640) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `orders` | array | yes | Complete SignedOrder objects. |
| `should_fail` | boolean | no | Revert the batch if any order fails. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

btcli tx execute-orders \

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.ExecuteOrders(orders=[...])

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

## On-chain implementation

`LimitOrders.execute_orders` — [`pallets/limit-orders/src/lib.rs#L615`](/code/pallets/limit-orders/src/lib.rs#L613-L640):

```rust
#[pallet::call_index(0)]
#[pallet::weight(Pallet::<T>::execute_orders_weight(orders))]
pub fn execute_orders(
    origin: OriginFor<T>,
    orders: BoundedVec<SignedOrder<T::AccountId>, T::MaxOrdersPerBatch>,
    should_fail: bool,
) -> DispatchResult {
    let relayer = ensure_signed(origin)?;
    ensure!(
        LimitOrdersEnabled::<T>::get(),
        Error::<T>::LimitOrdersDisabled
    );

    Self::check_authorized_batch_bound(&orders)?;
    for signed_order in orders {
        let order_id = Self::derive_order_id(&signed_order.order);
        if let Err(reason) = Self::try_execute_order(signed_order, order_id, &relayer) {
            if should_fail {
                // All-or-nothing: abort the batch, reverting prior orders.
                return Err(reason);
            }
            // Best-effort: individual order failures do not revert the batch.
            Self::deposit_event(Event::OrderSkipped { order_id, reason });
        }
    }

    Ok(())
}
```
