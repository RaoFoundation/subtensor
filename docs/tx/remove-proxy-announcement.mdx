Signed by the delegate that announced the call. Returns the announcement
deposit. Prefer this over `reject_proxy_announcement` when the real
account is a keyless pure proxy (it has no key to sign a reject).

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Proxy | [`Proxy.remove_announcement`](/code/pallets/proxy/src/lib.rs#L534-L549) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `real_ss58` | string | yes | Account the announcement targeted (the delegation's grantor). |
| `call_hash` | string | yes | Hash previously passed to announce_proxy_call (0x-prefixed hex). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## On-chain implementation

`Proxy.remove_announcement` — [`pallets/proxy/src/lib.rs#L539`](/code/pallets/proxy/src/lib.rs#L534-L549):

```rust
#[pallet::call_index(7)]
#[pallet::weight(T::WeightInfo::remove_announcement(
    T::MaxPending::get(),
    T::MaxProxies::get()
))]
pub fn remove_announcement(
    origin: OriginFor<T>,
    real: AccountIdLookupOf<T>,
    call_hash: CallHashOf<T>,
) -> DispatchResult {
    let who = ensure_signed(origin)?;
    let real = T::Lookup::lookup(real)?;
    Self::edit_announcements(&who, |ann| ann.real != real || ann.call_hash != call_hash)?;

    Ok(())
}
```
