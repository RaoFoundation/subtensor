Moves up to `amount_gamma` (`all` for the whole balance) from your
coldkey's gamma balance, the gamma it holds on no hotkey, to the deposit at
`hotkey_ss58`: the whole balance, or at least 0.1 gamma leaving at least
as much. A hotkey with no deposit opens one with no daily spend cap.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.deposit_gamma`](/code/pallets/subtensor/src/macros/dispatches.rs#L3294-L3303) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the balance and the deposit. |
| `hotkey_ss58` | string | yes | Hotkey of the deposit credited. |
| `amount_gamma` | number \| `"all"` | yes | Gamma moved. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.DepositGamma(netuid=1, hotkey_ss58="5F...", amount_gamma=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```
