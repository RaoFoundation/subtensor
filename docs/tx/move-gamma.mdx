Moves up to `amount_gamma` (`all` for the whole balance) from the
deposit at `origin_hotkey_ss58` to the one at
`destination_hotkey_ss58`. A destination with no deposit is opened with
the origin's spender and daily spend cap, and a move that empties the
origin closes it.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.move_gamma`](/code/pallets/subtensor/src/macros/dispatches.rs#L3180-L3190) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of both deposits. |
| `origin_hotkey_ss58` | string | yes | Hotkey of the deposit moved from. |
| `destination_hotkey_ss58` | string | yes | Hotkey of the deposit moved to. |
| `amount_gamma` | number \| `"all"` | yes | Gamma moved. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.MoveGamma(netuid=1, origin_hotkey_ss58="5F...origin", destination_hotkey_ss58="5G...destination", amount_gamma=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```
