Burns up to `amount_alpha` (`all` for the whole stake) of your stake
on `origin_hotkey_ss58` and credits its value in gamma to the deposit at
`hotkey_ss58`, valued as `mint_gamma` values bought alpha. The stake is
destroyed, not moved. `spender_ss58`, `service_hotkey_ss58` and
`daily_spend_cap_gamma` name the deposit's spender and cap as for
`mint_gamma`. Fails rather than minting less than the current quote
less `rate_tolerance`. Its plan's `preview` and result's
`data["minted"]` are as for `mint_gamma`.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the stake burned. |
| `hotkey_ss58` | string | yes | Hotkey of the deposit credited: an API key, not a staking hotkey. |
| `amount_alpha` | number \| `"all"` | yes | Alpha of stake burned. |
| `origin_hotkey_ss58` | string | yes | Hotkey the stake is held on (the validator backing the position). |
| `rate_tolerance` | number | no | Maximum fall of the minted gamma below the quote, as a fraction (0.05 = 5%). |
| `spender_ss58` | string | no | The account that spends the deposit. A new deposit opens with it, and an existing one must already name it. Omit to keep the deposit's spender, which for a new deposit is the spender of the subnet owner's service, otherwise the subnet owner, or its lease's beneficiary while a lease owns the subnet. |
| `service_hotkey_ss58` | string | no | Hotkey of a service published on the subnet, instead of a spender. The deposit names the spender the service publishes. |
| `daily_spend_cap_gamma` | number | no | The deposit's daily spend cap, in gamma; 0 pauses it. A new deposit opens with it, and an existing one must already have it. Omit to keep the deposit's cap, which for a new deposit is none. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.
