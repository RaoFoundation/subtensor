`name` is one of `enabled`, `min_burn`, `max_burn`, `half_life`,
or `increase_mult`. Min/max values are TAO amounts, half-life is blocks,
and increase multiplier is a decimal in 1..3 (or its raw U64F64 bits).
Changes require the subnet-owner coldkey or root, respect the owner's
rate-limit window, and are independent for each mechanism and channel.
Disabling burn makes subsequent channel commitments free apart from fees;
it does not refund earlier burns. Read the live decayed price and stored
settings with the `commit_burn` read.

## Verify

After inclusion, confirm the effect with the
[`commit-burn`](/docs/query/commit-burn) read:

```bash
btcli query commit-burn --netuid <integer> --mechid <integer> --channel <integer> --json
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet to configure; the signer must be its owner. |
| `name` | string | yes | Burn parameter: enabled, min_burn, max_burn, half_life, or increase_mult. |
| `value` | boolean \| integer \| number \| string | yes | Enabled flag, TAO min/max, block half-life, or 1..3 multiplier / raw U64F64 integer. |
| `mechid` | integer | no | Mechanism whose commitment channel to use. |
| `channel` | integer | no | Independent commitment channel; separate from the legacy commitment. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx set-commit-burn \
  --netuid <int> \
  --name <value> \
  --value <value> --dry-run
btcli tx set-commit-burn \
  --netuid <int> \
  --name <value> \
  --value <value> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.SetCommitBurn(netuid=1, name="...", value="...")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("set_commit_burn", {...}, wallet)
```
