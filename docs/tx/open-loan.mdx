A short locks TAO collateral, lifts borrowed alpha, and immediately sells
that alpha into escrow TAO (`proceeds`) on the position's custody account.
A long locks existing free alpha stake, lifts TAO, and buys escrow alpha
with the borrowed TAO (no free TAO payout). Debt stays in the borrowed
currency. Interest is 100% annually on opening loan value, charged in fixed
collateral units and collected every `InterestPeriod` blocks (runtime
constant; 50_400 ≈ 7 days at 12 s). There are no price-triggered
liquidations; exhausted collateral forfeits the position.

Alpha debt must also fit 25% of collateral at a conservative immediate
funded-redemption valuation, including payout rounding. TAO debt requires
conservative funded collateral backing. New borrowing must preserve each
other same-side loan's individual coverage after accrued interest. These
opening checks do not guarantee future repayment.

Positions are keyed by `(coldkey, netuid)`. An existing position must
have the same side. `collateral` adds to its remaining collateral after
accrued interest; borrowed principal and the new fixed coupon add to the
saved position. The old coupon is not repriced. The combined position must
pass current opening guards, and an already exhausted position cannot be
increased.

Shorts are TAO-only and must omit `hotkey_ss58` (the call passes
`source_hotkey=None`). Longs require `hotkey_ss58` as the stake that
supplies collateral alpha. `amount` selects exact additional principal:
alpha for shorts and TAO for longs. With no amount, the collateral
determines the borrowing limit. The runtime transfers exactly the
requested amount or refuses the call. `min_borrow` is a floor on
additional principal. `min_proceeds` is the short's minimum escrow TAO
from the forced sale (slippage floor); `min_escrow_alpha` is the long's
minimum escrow alpha from the forced buy. The call is atomic and refuses a
smaller loan or opening value. There remains one position per coldkey and
subnet; closing repays its total principal.

On fork / clone chains without a live MEV decryptor, submit with
`--no-mev-shield` (encrypted submission will never be decrypted).

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet to borrow against. |
| `side` | string | yes | short: lock TAO; long: lock subnet alpha. |
| `collateral` | number \| `"all"` | yes | Additional collateral to lock: TAO for a short, alpha for a long. |
| `hotkey_ss58` | string | no | Long only: hotkey whose free alpha supplies collateral. Omit for shorts (TAO-only; no hotkey on open). |
| `min_borrow` | number \| `"all"` | no | Minimum additional principal: alpha for a short, TAO for a long. |
| `min_proceeds` | number \| `"all"` | no | Minimum additional short opening value in TAO; unused for longs. |
| `min_escrow_alpha` | number \| `"all"` | no | Minimum escrowed alpha after a long's forced buy; unused for shorts. |
| `valid_until` | integer | no | Latest block number that may include this open. |
| `amount` | number \| `"all"` | no | Exact additional amount to borrow: alpha for a short, TAO for a long. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx open-loan \
  --netuid <int> \
  --side <value> \
  --collateral <amount|all> --dry-run
btcli tx open-loan \
  --netuid <int> \
  --side <value> \
  --collateral <amount|all> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.OpenLoan(netuid=1, side="...", collateral=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("open_loan", {...}, wallet)
```

pub fn open_exact(

    collateral: u64,

    principal: u64,
    min_proceeds: u64,

        owner,
        netuid,
        side,
        collateral,
        source_hotkey,
        Some(principal),

        min_proceeds,
