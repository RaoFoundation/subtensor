Charges accrued interest, starts deleveraging a position whose
median-TWAP equity is negative, or runs one deleverage step. Anyone may
submit it.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.poke`](/code/pallets/lending/src/lib.rs#L1048-L1054) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `owner_ss58` | string | yes | Owner of the short to check. |
| `netuid` | integer | yes | Subnet of the short. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx poke-short \
  --owner <ss58|name> \
  --netuid <int> --dry-run
btcli tx poke-short \
  --owner <ss58|name> \
  --netuid <int> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.PokeShort(owner_ss58="5F...", netuid=1)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("poke_short", {...}, wallet)
```
