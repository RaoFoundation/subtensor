Opens (or sizes) a long against alpha collateral and, in the same
extrinsic, sells additional unlocked alpha for free TAO. Either both
legs succeed or the call rolls back. `valid_until` is a block deadline.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.open_long_and_sell`](/code/pallets/lending/src/lib.rs#L1229-L1260) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet to raise against. |
| `hotkey_ss58` | string | no | Hotkey holding collateral and sale alpha. |
| `collateral_alpha` | number \| `"all"` | no | Exact alpha collateral for the long; omit to size from borrow_tao. |
| `borrow_tao` | number \| `"all"` | no | Exact TAO principal to borrow; omit to size from collateral_alpha. |
| `max_collateral_alpha` | number \| `"all"` | no | Ceiling on alpha collateral when sizing from borrow_tao. |
| `min_borrow_tao` | number \| `"all"` | no | Floor on borrowed TAO principal. |
| `sell_alpha` | number \| `"all"` | no | Unlocked alpha to sell for free TAO; omit to sell none. |
| `min_tao_out` | number \| `"all"` | no | Minimum free TAO from the raise sale leg. |
| `min_escrow_alpha` | number \| `"all"` | no | Minimum escrowed alpha after the long's forced buy. |
| `valid_until` | integer | no | Latest block number that may include this raise. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## Python

import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
