`changes` names the fields to change among `apr_bps`,
`charge_interval_blocks`, `equity_floor`, `min_interest_cover_blocks`,
`pace_bps_per_block`, `pause_twap_bps`, `pause_sma_bps`,
`min_pool_tao`, `min_notional`, `deposit`, `withdraw_buffer_blocks`,
`exit_hysteresis_bps`, `twap_samples` and `twap_interval_blocks`;
amounts are in rao. The rest keep their value. The chain checks the whole
group against its bounds, refuses it whole on any breach, and applies it
from the next block. Verify with the `lending_params` read.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `coldkey` | root (chain sudo) | Lending | [`Lending.set_lending_params`](/code/pallets/lending/src/lib.rs#L678-L683), `Sudo.sudo` |

## Verify

After inclusion, confirm the effect with the
[`lending-params`](/docs/query/lending-params) read:

```bash
btcli query lending-params --json
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `changes` | object | yes | Fields to change, by name; every other field keeps its value. The group is replaced whole from the next block, and a change the chain's bounds refuse changes nothing. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx set-lending-params \
  --changes '<json>' --dry-run
btcli tx set-lending-params \
  --changes '<json>' -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.SetLendingParams(changes={...})

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("set_lending_params", {...}, wallet)
```
