The combined position must still cover its whole-book share. Refused while
the position deleverages, while the subnet's dilution breaker is on, or
when the block's net mint limit is spent. `min_tao_out` floors the sale
of `extra_mint`; omit it to use the simulated sale less
`rate_tolerance`.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the short. |
| `extra_mint` | number | no | More alpha to mint and sell. |
| `extra_collateral` | number | no | More TAO collateral to lock. |
| `min_tao_out` | number | no | Least TAO the extra sale may return. Omit to quote it. |
| `rate_tolerance` | number | no | Tolerance applied to the quote when the floor or ceiling is omitted, as a fraction (0.005 = 0.5%). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.
