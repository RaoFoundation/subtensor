Mints and sells `amount_alpha` more alpha into the position, with
`collateral_tao` more collateral from your free balance (0 when the
position already covers the larger size). Interest due is settled from the
position's collateral first. The `quote_increase_short` read reports the
least collateral the larger position needs.
Fails rather than selling for less than the current quote less
`rate_tolerance`. A plan's `preview` holds the same quote keys as
`open_short`.

| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Lending | [`Lending.increase_short`](/code/pallets/lending/src/lib.rs#L506-L527) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet of the short. |
| `amount_alpha` | number | yes | Alpha minted and sold on top of the short. |
| `collateral_tao` | number | no | TAO moved from your free balance into the position as collateral. |
| `rate_tolerance` | number | no | Maximum fall of the sale's TAO proceeds below the quote, as a fraction (0.05 = 5%). |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx increase-short \
  --netuid <int> \
  --amount-alpha <amount> --dry-run
btcli tx increase-short \
  --netuid <int> \
  --amount-alpha <amount> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.IncreaseShort(netuid=1, amount_alpha=1.0)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("increase_short", {...}, wallet)
```
