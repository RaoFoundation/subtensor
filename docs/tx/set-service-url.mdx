The chain stores the url only; the document it points to (the services,
their interfaces, and the spender to name on gamma deposits) is the
publisher's. Signed by the hotkey, which must be registered on the subnet.
An empty url clears it. Updates wait out the subnet's `serving_rate_limit`.

| Signer | Origin | Pallet | Wraps |
| --- | --- | --- | --- |
| `hotkey` | signed account (pallet role may apply) | SubtensorModule | [`SubtensorModule.set_service_url`](/code/pallets/subtensor/src/macros/dispatches.rs#L3244-L3252) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet on which to publish the url. |
| `url` | string | yes | Url of the services document, up to 256 bytes; empty clears it. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx set-service-url \
  --netuid <int> \
  --url <value> --dry-run
btcli tx set-service-url \
  --netuid <int> \
  --url <value> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.SetServiceUrl(netuid=1, url="...")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:
