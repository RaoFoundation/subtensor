The old position is closed like `close`: the pool gets its slice and the
borrow fee back, and the owner's cushion plus profit or loss comes back in
TAO. That TAO, plus an optional `top_up`, is then the cushion of a fresh
position on the same side with a full lifetime and today's entry price.
Fails without touching the position if the new cushion is below the
minimum deposit or the pool cap is reached; `close` instead.

| --- | --- | --- | --- |
| `coldkey` | signed account (pallet role may apply) | Derivatives | [`Derivatives.roll`](/code/pallets/derivatives/src/lib.rs#L268-L278) |

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet the position is on. |
| `side` | string | yes | Which position to roll: `Short` or `Long`. |
| `top_up` | number \| `"all"` | no | Extra TAO to add to the new cushion from the coldkey balance. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx roll-derivative \
  --netuid <int> \
  --side <value> --dry-run
btcli tx roll-derivative \
  --netuid <int> \
  --side <value> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.RollPosition(netuid=1, side="...")

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("roll_derivative", {...}, wallet)
```
