The loan opening value (or remaining dust after a partial repay) is below the runtime minimum (~0.001 TAO), and side capacity is not the binder. Increase collateral / principal, or close the remainder fully. When the side cap is what blocks a minimum loan, the call returns SideCapacity instead.
