A mint named a spender, but the gamma deposit it credits already names another. A named spender opens a new deposit and must match an existing one. Mint without naming one, or change the deposit's spender with `set_gamma_deposit_spender` first.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`invalid_argument`](/docs/errors/invalid-argument).

## Remediation

The deposit already names another spender (`btcli gamma show`); mint without `--spender` or `--service-hotkey`, or change it with `btcli gamma set-spender` first
