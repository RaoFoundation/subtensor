After normalization, one of the submitted weights exceeds the subnet's maximum weight limit (self-weight is exempt). Check the `MaxWeightsLimit` hyperparameter (`btcli subnets hyperparameters`) and flatten the weight vector before setting.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`limit_exceeded`](/docs/errors/limit-exceeded).

## Remediation

A chain-side capacity limit was hit; reduce the size or count of the request

The same explanation is available in the terminal: `btcli explain MaxWeightExceeded`.
