A mint named a daily spend cap, but the gamma deposit it credits has another, or it credits a balance, which has none. A named cap opens a new deposit and must match an existing one's. Mint without naming one, or change the deposit's cap with `set_gamma_deposit_daily_spend_cap` first.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`invalid_argument`](/docs/errors/invalid-argument).

Declared at [`pallets/subtensor/src/macros/errors.rs#L486`](/code/pallets/subtensor/src/macros/errors.rs#L486).

## Remediation

The deposit already has another daily spend cap (`btcli gamma show`), or the mint credits your balance, which has none; mint without `--daily-spend-cap-gamma`, or change the deposit's cap with `btcli gamma set-cap` first
