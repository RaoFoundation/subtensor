The requested subnet UID capacity exceeds its consensus limit. Null consensus allows `MaxAllowedUids` up to 2500 independently of mechanism count. Yuma consensus requires max UIDs times mechanism count to remain at most 256. Reduce `MaxAllowedUids`, reduce the mechanism count on Yuma, or switch to a consensus mode that supports the capacity.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`limit_exceeded`](/docs/errors/limit-exceeded).
