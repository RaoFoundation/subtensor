Slot 3 (validator) of the emission weight vector is at or below root's baseline share. Every block the chain pays root `min(V, r)` of the subnet's emission off the top of the validator slot, where `r = V0 * x / (x + A)` is what root would earn with the default validator share V0 (0.41) and the global TaoWeight (`x` = root TAO times that weight, `A` = the subnet's alpha issuance), recomputed from live state; alpha validators get `V - min(V, r)`. A set with `V <= r` would leave validators nothing, so it is rejected. `btcli subnets emission show --netuid <n>` prints the baseline and the floor for this block. Raise the validator share above it and resubmit.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`policy_violation`](/docs/errors/policy-violation).
