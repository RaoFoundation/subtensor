This legacy error is retained for older runtimes that disabled PoW registration. Upgraded runtimes let the subnet owner enable network_pow_registration_allowed; general registration must also be enabled. Root does not accept PoW registration.

Declared by the `AdminUtils` pallet; it classifies to the semantic code [`disabled`](/docs/errors/disabled).

Declared at [`pallets/admin-utils/src/lib.rs#L220`](/code/pallets/admin-utils/src/lib.rs#L220).
