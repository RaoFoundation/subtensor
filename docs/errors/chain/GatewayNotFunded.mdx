The account named as the gateway does not hold the existential deposit. Send it that much first: the hub hands the gateway only what it pays on to the transport.

Declared by the `Rails` pallet; it classifies to the semantic code [`insufficient_balance`](/docs/errors/insufficient-balance).

Declared at [`pallets/rails/src/lib.rs#L460`](/code/pallets/rails/src/lib.rs#L460).

## Remediation

Fund the signing account or reduce the amount; check with `btcli wallet balance`

The same explanation is available in the terminal: `btcli explain GatewayNotFunded`.
