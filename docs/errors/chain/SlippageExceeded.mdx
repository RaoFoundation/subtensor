A forced trade missed your min-out / max-payment limit (open, raise, close, or repay). Re-quote (btcli loan show / the same command), then raise --max-slippage above the default 1% or reduce size. Zero --max-slippage always fails once the next block moves the price. The CLI help line shows quoted payment/refund vs your bounds when available.

Declared by the `Lending` pallet; it classifies to the semantic code [`insufficient_liquidity`](/docs/errors/insufficient-liquidity).

Declared at [`pallets/lending/src/lib.rs#L1179`](/code/pallets/lending/src/lib.rs#L1179).
