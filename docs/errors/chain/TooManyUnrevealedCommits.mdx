Legacy hash commits (`commit_weights` and `commit_mechanism_weights`) reached their fixed limit of 10 unexpired entries in `WeightCommits` for this hotkey and mechanism. Reveal one or wait for it to expire. For a Yuma CRv3 timelocked commit, the hotkey reached the subnet's `MaxTimelockedCommitsPerHotkey` limit in the current mechanism and commit epoch. Check that setting and `TimelockedWeightCommits`. A setting of 0 pauses new Yuma commits even with an empty queue; root must raise it before retrying. Otherwise, retry in a later commit epoch or after root raises the cap.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`limit_exceeded`](/docs/errors/limit-exceeded).
