Escrow plus collateral cannot cover this repay/close path (or free TAO cannot cover an underwater-short top-up). Check lending_close_quote / lending_repay_quote for payment, leftover refund, and shortfall; fund free TAO for the top-up or use --from-wallet (alias: --repay-from-wallet). Insolvent longs forfeit at expiry if still uncovered. Accrued interest reduces usable collateral.

Declared by the `Lending` pallet; it classifies to the semantic code [`insufficient_balance`](/docs/errors/insufficient-balance).

Declared at [`pallets/lending/src/lib.rs#L1278`](/code/pallets/lending/src/lib.rs#L1278).

## Remediation

Fund the signing account or reduce the amount; check with `btcli wallet balance`
