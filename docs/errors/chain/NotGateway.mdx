Only the gateway contract's account (`Rails.Gateway`) delivers orders and takes messages from the outbox. This call is not for accounts. An exit, and a payment into a bridge's budget, also fail with this while no gateway account is set: there is nobody to pay.

Declared by the `Rails` pallet; it classifies to the semantic code [`not_authorized`](/docs/errors/not-authorized).

Declared at [`pallets/rails/src/lib.rs#L368`](/code/pallets/rails/src/lib.rs#L368).

## Remediation

Sign with the key or origin that owns the target object, then retry
