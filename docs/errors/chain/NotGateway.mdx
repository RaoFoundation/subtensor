Only the gateway contract's account (`Rails.Gateway`) delivers orders and takes messages from the outbox. This call is not for accounts. An exit also fails with this while an exit fee is set and no gateway account is: there is nobody to pay.

Declared by the `Rails` pallet; it classifies to the semantic code [`not_authorized`](/docs/errors/not-authorized).

Declared at [`pallets/rails/src/lib.rs#L320`](/code/pallets/rails/src/lib.rs#L320).

## Remediation

Sign with the key or origin that owns the target object, then retry

The same explanation is available in the terminal: `btcli explain NotGateway`.
