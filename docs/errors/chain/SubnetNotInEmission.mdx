The subnet is not in the emission set (it currently receives no share of the block emission), so a short cannot be opened or increased there. Closing a short and adding collateral stay available. Use a subnet that receives emission, or retry once this one does.

Declared by the `Lending` pallet; it classifies to the semantic code [`policy_violation`](/docs/errors/policy-violation).

Declared at [`pallets/lending/src/lib.rs#L444`](/code/pallets/lending/src/lib.rs#L444).

## Remediation
