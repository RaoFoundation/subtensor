A queued root-dividend deposit on this validator could not be settled yet, so an operation that changes the claimant base or basket was refused. Wait for the block queue processor to settle the dividend, then retry. Settlement also requires the affected basket prices to be within their fast-EMA band; user calls cannot force a dividend mint between pool swaps.
