Only an empty gamma deposit can be closed. Moving, withdrawing or sending its whole balance closes it; once its hotkey has spent it to zero, close it.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`invalid_argument`](/docs/errors/invalid-argument).

Declared at [`pallets/subtensor/src/macros/errors.rs#L482`](/code/pallets/subtensor/src/macros/errors.rs#L482).

## Remediation

Move the balance out with `btcli gamma move --amount-gamma all`, which closes the deposit, or close it once its hotkey has spent it

The same explanation is available in the terminal: `btcli explain GammaDepositNotEmpty`.
