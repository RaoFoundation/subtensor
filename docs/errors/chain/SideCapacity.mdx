Side-cap headroom cannot fit this borrow (or any MinimumLoanValue-sized borrow) even at full Cap. A large top-up can still hit this when remaining capacity is exhausted. Reduce size or wait for repayment; inspect lending_reserves for headroom. When only the new-subnet Cap ramp is binding, the call returns SideCapacityRamping instead.
