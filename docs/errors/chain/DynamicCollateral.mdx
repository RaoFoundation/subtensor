Collateral is below the dynamic valuation requirement at the current LTV tier (opens / increases), or escrow + collateral cannot cover buy-back / repay under LTV on roll. Add collateral (btcli lending add-collateral / AddLoanCollateral) or reduce principal; re-quote with lending_raise_quote / lending_open_quote (or btcli lending show).

Declared by the `Lending` pallet; it classifies to the semantic code [`insufficient_balance`](/docs/errors/insufficient-balance).

Declared at [`pallets/lending/src/lib.rs#L1714`](/code/pallets/lending/src/lib.rs#L1714).

## Remediation

Fund the signing account or reduce the amount; check with `btcli wallet balance`
