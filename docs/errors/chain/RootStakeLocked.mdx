A root (netuid 0) unstake was attempted before `RootStakeUnlockInterval` blocks elapsed since the coldkey/hotkey's last root stake add or remove. Check `LastColdkeyHotkeyStakeBlock` against the current block and wait out the hold window (or leave the interval at 0 via sudo if the lock is not intended).

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`too_early`](/docs/errors/too-early).
