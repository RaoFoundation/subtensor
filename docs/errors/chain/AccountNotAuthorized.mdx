The signing coldkey does not own the target registered hotkey. Sign `set_commitment_to` with the hotkey's owner coldkey; hotkeys cannot fund channel commitments.

Declared by the `Commitments` pallet; it classifies to the semantic code [`not_authorized`](/docs/errors/not-authorized).

Declared at [`pallets/commitments/src/lib.rs#L256`](/code/pallets/commitments/src/lib.rs#L256).

## Remediation

Sign with the key or origin that owns the target object, then retry
