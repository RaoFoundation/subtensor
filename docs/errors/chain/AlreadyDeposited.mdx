The account calling safe-mode `enter` or `extend` already has a safe-mode deposit on hold, so another cannot be placed. Check the account's `Deposits` entries and its balance held under the `EnterOrExtend` hold reason.

Declared by the `SafeMode` pallet; it classifies to the semantic code [`already_exists`](/docs/errors/already-exists).

## Remediation

The object or state already exists; treat the goal as met or pick a different target
