---
title: Subnet services
description: Services that registered hotkeys publish on their subnet, with a url to a document of their services and the spender their customers name on gamma deposits.
---

Any hotkey registered on a subnet can publish a service with
[`set-service`](/docs/tx/set-service), so that apps and agents can find what the
subnet serves and how it is paid for. A service is a url to a document of its
services and the spender its customers name on [gamma](/docs/guides/gamma)
deposits. Without a spender, the hotkey spends, so it signs the spends and pays
their fees. Publishing an empty url clears the service. Publishing is free, as serving an axon is, and uses the subnet's
[`serving_rate_limit`](/docs/hyperparameters/serving-rate-limit), so a service
can be changed or cleared only that many blocks after its own last update,
whatever the hotkey's axon does.

```bash
btcli tx set-service --netuid 51 --url https://example.com/services.json -w my_coldkey -H my_hotkey
btcli query services --netuid 51
```

```python
await client.execute(bt.SetService(netuid=51, url="https://example.com/services.json"), hotkey_wallet)
services = await client.subnets.services(netuid=51)  # {hotkey: {url, spender, block, owner}}
```

A service follows a hotkey swap and is removed when its neuron is
deregistered. `owner` marks the service of the subnet owner's hotkey. Customers
name its spender by minting with `--service-hotkey` (see
[Gamma](/docs/guides/gamma#minting)).

## The document

The chain stores the url and the spender. The document says what the services
are, how to reach them, and how they are paid for:

```json
{
  "version": 1,
  "services": [
    { "type": "openapi", "endpoint": "https://…", "spec": "https://…/openapi.json" },
    { "type": "mcp", "endpoint": "https://…/mcp" }
  ],
  "payments": [
    { "type": "gamma" },
    { "type": "x402" }
  ]
}
```

- A `gamma` payment accepts the subnet's [gamma](/docs/guides/gamma), from
  deposits that name the service's spender.
- An [`x402`](https://www.x402.org) payment states its price and payee in each
  HTTP 402 response.
- Readers skip service and payment types they do not know.

A service can name any spender, and that spender can spend the deposits that
name it without serving, so prefer the service marked `owner`.
