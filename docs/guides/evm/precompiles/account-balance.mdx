## Proposed operations

| Proposed function | Source extrinsic |
|---|---|
| `burnBalance` | `Balances.burn` |
| `upgradeAccounts` | `Balances.upgrade_accounts` |

`upgradeAccounts` must have an explicit fixed input bound. The implementation
must dispatch the highest-level Balances call as the mapped signer and preserve
all runtime authorization and issuance invariants. Force operations require
Root and are not exposed.

Proposed names and signatures do not reserve selectors.
