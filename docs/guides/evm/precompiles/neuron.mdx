Registers neurons, publishes serving endpoints, and submits weights. Every
function is `payable`.

## Functions

```text
burnedRegister(uint16,bytes32)
registerLimit(uint16,bytes32,uint64)

setWeights(uint16,uint16[],uint16[],uint64)

```
