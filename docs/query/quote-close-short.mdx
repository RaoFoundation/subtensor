{/* GENERATED by scripts/generate.py from the SDK registries — do not edit. */}

The `alpha` bought back (the request capped at the short's size), its
`cost` in TAO with the parts paid `from_proceeds` and `from_collateral`,
the `interest` settled from the collateral first, and whether the close is
`full`, which returns the remaining collateral and the deposit.

**Category:** Lending

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `coldkey_ss58` | string | Coldkey holding the short. |
| `netuid` | integer | Subnet of the short. |
| `amount_alpha` | number | Alpha bought back; more than the short's size quotes closing it whole. |
