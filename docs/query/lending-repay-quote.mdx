Same payment/refund/shortfall units as :func:`lending_close_quote`, sized
for `principal_part`. Full principal delegates to the close quote on
chain.

**Category:** Prices & swaps

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `coldkey_ss58` | string | Position owner. |
| `netuid` | integer | Subnet of the position. |
| `principal_part` | string | Principal to repay: alpha for a short, TAO for a long. Must be > 0 and ≤ stored principal; full principal matches lending_close_quote. |
| `hotkey_ss58` | string | Optional per-call hotkey for alpha repay (short wallet path) or alpha refund (long repay). Omit for short escrow buyback (TAO only). |
| `repay_from_wallet` | boolean | False / --from-escrow (default): quote the escrow AMM path for the slice. True / --from-wallet (alias --repay-from-wallet): repay short alpha from a call-supplied hotkey stake. |
