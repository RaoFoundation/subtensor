Reads are free, unsigned, and safe to call at any time. Each CLI command is `btcli query <name>` (add `--json` for machine-readable output). In Python every read is a typed method on its category's namespace — `sub.subnets.subnet_registration_cost()`, `sub.delegation.delegates()` on `sub = bt.Subtensor()` (awaited on the async client) — with autocomplete and signature help; `sub.read("<name>", ...)` dispatches the same read by name. The machine-readable catalog is at [`/catalog/reads.json`](/catalog/reads.json) or via `bt.reads.list_reads()`.

## Hyperparameters

| Query | Summary |
