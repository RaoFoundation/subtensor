## Reproduced production defect and regression

Registered-wallet Shield quotes previously discarded an explicitly requested inner nonce and encoded the current nonce instead. At nonce 63, the real inner nonce 64 adds a SCALE compact byte: actual ciphertext sizes 8,193 and 32,769 were quoted as 8,192 and 32,768 for all four registered schemes. This selected the wrong carrier tier or admitted a quote beyond the carrier cap. `_sign_hashed` now preserves explicit nonces while private signing still validates chain authority and the Shield generation offset.

The before/after JSON uses the native codec and real proof/encryption bytes. Forty-eight new regressions cover compact nonce boundaries 63, 16,383, and 2^30−1 at four carrier-size boundaries; replaying only the original method fails all 48. The fixed focused suite passed 127 tests. The full SDK unit run passed 3,105 with one skip before the other worker's separate keyfile-atomicity additions. The parent release report records later integrated checks and actual nonce-63 Shield execution.

## Static conclusions and limits

All generated calls reach the common executor/transport signing path. Recipient-bearing wrappers preserve descriptor data until atomic registration/payment or a finalized-registration check. Transport signing derives authority from finalized chain state, checks descriptor and commitment, and does not persist a mutable local generation counter. Shield allocates consecutive outer/inner generations and nonces from one authority snapshot. Order receiving descriptors and nonbatchable EVM receiving paths require finalized registration.

The metadata construction inventory covers 277 development dispatchables (276 production plus the development-only faucet): 123 wrappers and 154 explicit raw-call paths. Its origin classifications and source regressions are static evidence, not a claim that every business state was executed live. Root-only, unsigned, deprecated, and contract-adapter calls retain their own origin rules. Generic failed SDK results currently omit triggered events and fee even though the lower transport preserves them; this predates MS and the release fixtures query finalized events when needed.

Bare SS58 addresses cannot disclose an unregistered account's descriptor. Descriptor-bearing addresses permit sponsorship; pre-funded bare accounts can be registered later and spend their existing funds, covered by the parent's release scenarios. Native Substrate EVM calls support MS authority; raw Ethereum RLP remains secp256k1. Hardware devices and the classical-only Vault adapter require their own ML-DSA support. Protected multisig quorums and detached capability roles retain deliberate authorization requirements.

No finite test suite proves absence of every implementation error or covers every future economic state. Full emission histories, all proxy timing permutations, every contract extension and every business-rule input require separate targeted coverage. The parent release report consolidates runtime matrices, cryptographic review, keyfile failure injection, additional live operation families, migration checks, and remaining deployment conditions.
