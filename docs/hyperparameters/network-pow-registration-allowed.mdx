---
title: "network_pow_registration_allowed"
description: "Control proof-of-work miner registration on a null-consensus subnet."
---

`network_pow_registration_allowed` gates proof-of-work admission on
[null-consensus subnets](/docs/guides/null-consensus). The subnet owner or root
can change this flag using `AdminUtils.sudo_set_network_pow_registration_allowed`,
subject to the normal admin window and owner rate limit.

Both this flag and `registration_allowed` must be true for PoW registration.
`btcli pow register --netuid N` solves work for the wallet hotkey and signs with
its coldkey. Valid work pays no registration burn or collateral; transaction
fees still apply. The runtime checks work freshness, difficulty, replay,
account association, capacity, and the per-block registration limit.

On ordinary Yuma subnets, PoW remains unavailable: the toggle returns
`POWRegistrationDisabled`, and the legacy `register` call retains its burn-based
behavior. Setting this flag does not convert an existing subnet to null consensus.
Toggle `null_consensus_enabled` through the normal hyperparameter setter:
`btcli hparams set --netuid N --name null_consensus_enabled --value true`.
