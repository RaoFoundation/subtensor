---
title: yuma_version
description: "The active consensus mode: Null_Consensus, Yuma 2, or Yuma 3."
---

`yuma_version` reports the active consensus mode:

- **`Null_Consensus`** when [`null_consensus_enabled`](/docs/hyperparameters/null-consensus-enabled) is true.
- **2** for classic Yuma.
- **3** for Yuma3.

Null mode takes precedence over the preserved `yuma3_enabled` setting. Disabling
null mode makes this field report the configured Yuma version again.

## API compatibility

The V3 hyperparameters runtime API returns `Null_Consensus` as a text value;
Yuma versions remain numeric. The SDK exposes the same values in its flat
hyperparameters mapping. The deprecated V2 API keeps its fixed numeric SCALE
layout and represents null mode as **0**.

This field is derived from the mode flags. There is no separate `YumaVersion`
storage item, and it cannot be set directly.

## Reading and setting

```bash
btcli sudo get --netuid N --name yuma_version
```

The subnet owner enables null mode through its hyperparameter:

```bash
btcli sudo set --netuid N --name null_consensus_enabled --value true
```

Use `--value false` to resume Yuma. The preserved
[`yuma3_enabled`](/docs/hyperparameters/yuma3-enabled) flag selects Yuma 2 or 3.
